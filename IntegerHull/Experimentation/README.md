# Benchmarking for IntegerHull

This directory contains benchmarking scripts and input files designed to assess the performance of integer hull methods implemented within the **PolyhedralSets** library.

---

## 📂 Directory Structure
```
Benchmarks/
│── Input/                          # Directory containing input test cases
|── PythonScript/                   # Directory containing plots generating plots from benchmark results
│── benchmarking.tst                # Maple script utilized for executing tests
│── test-harness.tst                # Tests in Maple format
│── Makefile                        # Automation script for executing benchmarks
│── results_*.output                # Files containing raw execution results
│── BENCHMARKING_results_*.output   # Files containing filtered benchmark-specific results
│── crash_log.txt                   # Log file capturing errors encountered during execution
```
---

## 🔍 Modes
Benchmarks evaluate two modes of the **IntegerHull** procedure:

- **newmethod** — our optimized 2D integer-hull algorithm  
- **oldmethod** — Maple’s original integer-hull procedure (reference method)

Both methods are tested on the same set of input files found in `Input/`.

---

## 🚀 Running All Benchmarks
To execute all benchmarks, simply run:

```sh
make all
```
Alternatively, specific tests can be executed as follows:
```sh
make test_newmethod    # Executes IntegerHull with mode newmethod
make test_oldmethod    # Executes IntegerHull with mode oldmethod
```

---

## 📊 Output Files
Results from the benchmarking process are stored in the following files:

### 📝 Raw Execution Results
- `results_newmethod.output` → **IntegerHull(P, mode=newmethod)**
- `results_newmethod.output` → **IntegerHull(P, mode=oldmethod)**

### 📈 Filtered Benchmark Results
- `BENCHMARKING_results_newmethod.output`
- `BENCHMARKING_results_oldmethod.output`
---

# 📊 Plot Generation for IntegerHull Benchmarks

The `PythonScript/` directory contains the plotting utilities used to generate all figures in **Section 7 (Experimentation)** of the paper.  
These plots visualize running time, speedup, dimension/vertex effects, and brute-force enumeration statistics for both the **new** and **old** integer hull methods.

---

## 📂 Files
```
│── plotgenerator.py        # Main script that parses benchmark data and generates plots
|── *.png                   # Output plots generated by the script
```

---

## 📥 Requirements
The plotting script requires **Python 3** and the following packages:

```sh
pip install matplotlib numpy
```
## ▶️ Running the Plot Generator
From the `PythonScript/` directory, run:
```sh
python3 plotgenerator.py
```

The script automatically:
1. Reads benchmark outputs:
- `BENCHMARKING_results_newmethod.output`
- `BENCHMARKING_results_oldmethod.output`
2. Matches tests with their metadata (dimension, vertices, volume, brute-force counts)
3. Normalizes infinite volumes
4. Produces all figures used in the paper
---
## ⚠️ Error Handling
If errors occur during execution, they will be logged in `crash_log.txt`, including:
- The input file that triggered the error
- The method and mode used during execution
- The corresponding error message from Maple

---

## 🛠 Cleanup Procedure
To remove all generated output files and logs, execute:
```sh
make clean
```
